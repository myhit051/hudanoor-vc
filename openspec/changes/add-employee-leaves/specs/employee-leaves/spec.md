## ADDED Requirements

### Requirement: บันทึกการลา
Admin SHALL บันทึกการลาของพนักงานที่ยังทำงานอยู่ได้ทีละวันหรือเป็นช่วง (ไม่เกิน 31 วัน) แบบเต็มวันหรือครึ่งวัน พร้อมประเภทและหมายเหตุ โดยวันเดียวกันของพนักงานคนเดียวรวมกันได้ไม่เกิน 1 วัน

#### Scenario: ลาหลายวัน
- **WHEN** Admin บันทึกลาเต็มวัน 1–3 ต.ค.
- **THEN** มีรายการลา 3 แถว แถวละ 1 วัน

#### Scenario: บันทึกซ้ำ
- **WHEN** วันนั้นมีลาเต็มวันอยู่แล้ว แล้วบันทึกเพิ่ม
- **THEN** ระบบตอบ 409 และไม่บันทึก

#### Scenario: ไม่ใช่ Admin
- **WHEN** ผู้ใช้ที่ไม่ใช่ Admin หรือไม่ล็อกอินเรียก API การลา
- **THEN** ระบบตอบ 403

### Requirement: หักลาเกินในเงินเดือน
เมื่อสร้างรอบหรือคำนวณเงินเดือนใหม่ ระบบ SHALL หัก (ลารวมในเดือน − วันลาที่ได้ต่อเดือน) × เงินเดือน ÷ 25 จากคอมก่อน ส่วนที่คอมไม่พอหักจากเงินเดือน และยอดรับไม่ต่ำกว่า 0 · พนักงานที่ยังไม่ตั้งวันลาที่ได้ไม่ถูกหัก

#### Scenario: คอมไม่พอ
- **WHEN** เงินเดือน 10,000 คอม 300 วันลาที่ได้ 2 ลา 3.5 วัน
- **THEN** หัก 600 (คอม 300 + เงินเดือน 300) ยอดรับ 9,700 และใบแจ้งเงินเดือนแสดงรายการหักแยกส่วน

#### Scenario: คำนวณใหม่
- **WHEN** แก้การลาแล้วกด "คำนวณใหม่"
- **THEN** ยอดหักอัปเดต โดยช่องปรับปรุงและสถานะจ่ายเดิมคงอยู่
